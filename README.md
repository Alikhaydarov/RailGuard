# RailGuard (Paper plugin)

Temir yolni avtomatik tuzatadi, ishlatilmayotgan vagonlarni o'chiradi, relslar atrofini dushman moblardan himoya qiladi.

**Build:** GitHub Actions -> Artifacts -> `RailGuard` (ichida `RailGuard.jar`), yoki lokal `mvn package`.

**Aternos:** Paper/Spigot server tanlang, jar ni `plugins` papkasiga yuklang.

**Buyruqlar (op):** `/railguard scan [radius]` | `forget [radius]` | `info` | `reload`
